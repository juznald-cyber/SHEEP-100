✅ Lista de Verificación Paso a Paso (23 min en total)

Abrir Meta for Developers ↗
  1. Entra a developers.facebook.com, inicia sesión con tu Facebook personal y haz clic en "Mis aplicaciones" → "Crear aplicación".
  2. Si te pregunta caso de uso, elige "Otros" (Other) al final de la lista y luego selecciona el tipo "Empresa" (Business).
  3. Asigna un nombre (ej. SHEEP 100), pon tu correo y haz clic en "Crear app".
✔ Verificación: Verás el panel principal con tu Identificador de la app (App ID) arriba a la izquierda, y el selector dirá "En desarrollo".
  1. En el panel principal (Dashboard) de tu app en Meta, baja hasta la sección "Agregar productos a tu app".
  2. Busca Instagram Graph API (o Instagram) y haz clic en el botón "Configurar" (Set Up).
✔ Verificación: El producto aparecerá listado en el menú lateral izquierdo de tu aplicación.
  1. Como creador de la app ya eres Administrador. Si tu Página de Facebook e Instagram están en ese mismo perfil, ya estás autorizado.
  2. Si deseas autorizar otra cuenta tuya, ve en el menú izquierdo a Roles de la app → Roles.
  3. Haz clic en "Agregar personas", elige Evaluador (Tester), ingresa tu usuario y acepta la invitación en Facebook.
✔ Verificación: Tu cuenta figura como Administrador o Evaluador activo en Modo Desarrollo.
  1. Asegúrate de que tu cuenta de Instagram sea de tipo Empresa (Business) o Creador (en la app móvil de Instagram: Configuración → Tipo de cuenta y herramientas).
  2. Entra a tu Página de Facebook en el navegador → Configuración → Cuentas vinculadas (Linked Accounts) → Instagram y haz clic en Conectar cuenta.
✔ Verificación: Tu Página de Facebook y tu Instagram profesional están oficialmente enlazados (puente obligatorio de Meta).
Abrir Graph API Explorer ↗
  1. Abre Graph API Explorer y selecciona tu App en el desplegable superior derecho "Meta App".
  2. En Permissions (Permisos), añade estos 4 permisos clave (haz clic para copiar):
    instagram_basic 📋 instagram_content_publish 📋 pages_show_list 📋 pages_read_engagement 📋
  3. Haz clic en el botón azul "Generate Access Token", selecciona tu Página de Facebook y tu cuenta de Instagram en la ventana emergente y autoriza.
  4. Copia el código largo generado (EAA...) y pégalo en el panel de conexión de la derecha 👉.
✔ Verificación: Al pegar tu token a la derecha y pulsar "Autodetectar Cuenta con Meta", SHEEP 100 rellenará tu ID de Instagram automáticamente y lo sincronizará en Firebase.

⚙️ Flujo Oficial de 2 Pasos de Meta Graph API

Instagram Graph API publica mediante 2 peticiones POST consecutivas (acepta imágenes JPG y videos MP4 con URL pública): 

// PASO 1: Crear el contenedor de medios en Meta
POST https://graph.facebook.com/v21.0/{IG_USER_ID}/media
Body: {
  image_url: "https://tu-dominio.com/foto.jpg",
  caption: "Tu copy con #hashtags",
  access_token: "EAA..."
}

// PASO 2: Publicar el contenedor (media_publish)
POST https://graph.facebook.com/v21.0/{IG_USER_ID}/media_publish
Body: {
  creation_id: "17895695668004550",
  access_token: "EAA..."
}

⚙️ Flujo Oficial TikTok Content Posting API

TikTok publica videos MP4 mediante la API /v2/post/publish/video/init/: 

// Petición directa a TikTok Content Posting API
POST https://open.tiktokapis.com/v2/post/publish/video/init/
Headers: {
  Authorization: "Bearer act.tiktok_token...",
  "Content-Type": "application/json"
}
Body: {
  post_info: {
    title: "Tu copy con #hashtags",
    privacy_level: "PUBLIC_TO_EVERYONE"
  },
  source_info: {
    source: "PULL_FROM_URL",
    video_url: "https://tu-servidor.com/video.mp4"
  }
}
