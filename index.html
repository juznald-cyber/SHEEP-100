✅ Lista de Verificación Paso a Paso

Abrir Meta for Developers ↗
  1. Entra a developers.facebook.com, inicia sesión con tu Facebook personal y haz clic en "Mis aplicaciones" → "Crear aplicación".
  2. Elige "Otros" (Other) y luego selecciona el tipo "Empresa" (Business).
  3. Asigna el nombre SHEEP 100 y haz clic en "Crear app".
  1. En el panel principal de tu app en Meta, baja a "Agregar productos a tu app".
  2. Busca Instagram Graph API y haz clic en "Configurar" (Set Up).
  1. Como creador de la app ya eres Administrador autorizado en Modo Desarrollo.
  2. Si quieres agregar otra cuenta tuya, ve a Roles de la app → Roles → Agregar personas (Tester).
  1. Verifica que tu cuenta de Instagram sea Empresa (Business) o Creador.
  2. En tu Página de Facebook ve a Configuración → Cuentas vinculadas → Instagram y conéctala.
Abrir Graph API Explorer ↗
  1. Abre Graph API Explorer y selecciona tu App.
  2. Añade estos 6 permisos (incluye pages_manage_posts para publicar en tu Página de Facebook e instagram_manage_insights para métricas):
    instagram_basic 📋 instagram_content_publish 📋 instagram_manage_insights 📋 pages_show_list 📋 pages_read_engagement 📋 pages_manage_posts 📋 (Facebook)
  3. Haz clic en "Generate Access Token", autoriza tu página e Instagram y pega el token a la derecha 👉.

⚙️ Cómo publica SHEEP 100 tanto Posts como Historias

Para Historias (Stories), Meta usa el mismo endpoint cambiando media_type: "STORIES": 

// OPCIÓN A: Post Normal de Feed
POST https://graph.facebook.com/v21.0/{IG_USER_ID}/media
Body: { image_url: "https://.../post.jpg", caption: "..." }

// OPCIÓN B: Historia de 24h (Story)
POST https://graph.facebook.com/v21.0/{IG_USER_ID}/media
Body: { media_type: "STORIES", image_url: "https://.../historia.jpg" }

// PASO 2 COMÚN: Publicar contenedor
POST https://graph.facebook.com/v21.0/{IG_USER_ID}/media_publish
Body: { creation_id: "ID_CONTENEDOR" }
🎵 TIKTOK CONTENT POSTING API v2 • SUBIDA BINARIA DESDE GOOGLE DRIVE

Conecta tu TikTok (@cocuyo.grafic) sin rechazos de Dominio ni Comandos Manuales

SHEEP 100 utiliza el modo oficial FILE_UPLOAD (Transferencia Binaria de Chunks MP4). Esto significa que cuando programas un video desde Google Drive, nuestro servidor y el Motor 24/7 en la Nube (con tu PC apagado) descargan el archivo .mp4 en memoria y se lo inyectan directamente a TikTok sin pedirte verificar el dominio drive.google.com.

✅ Cómo Funciona tu Conexión con TikTok en 4 Pasos

Abrir TikTok Developers ↗
  1. Entra a developers.tiktok.com/apps, selecciona tu App y activa el modo Sandbox.
  2. En Target Users (Usuarios de prueba) agrega tu cuenta @cocuyo.grafic.
  3. En Products añade Login Kit y Content Posting API (activa el switch Direct Post).
  4. En Scopes habilita los 3 permisos: user.info.basic, video.publish y video.upload.
  1. Dentro de tu Sandbox en TikTok Developers, baja a la sección Login Kit → Redirect URI.
  2. Asegúrate de tener registrada exactamente una de estas direcciones (haz clic para copiar):
    https://juznald-cyber.github.io/SHEEP-100/ 📋 https://sheep-100-b8a90.web.app/ 📋
  1. A la derecha 👉 verifica tu Client Key (ya pre-cargado: sbawbyxlo8yktgrxxv) y pega tu Client Secret de TikTok Sandbox.
  2. Haz clic en "🔗 1. Autorizar con TikTok (OAuth 1 Clic)".
  3. Al regresar a SHEEP 100, la aplicación detectará el código ?code=... en la URL y lo canjeará automáticamente por tu Access Token + Refresh Token (365 días) sin que tengas que usar PowerShell.
  1. Modo Direct Post (Sandbox): El video MP4 de tu Google Drive se publica directo en tu perfil @cocuyo.grafic con privacidad Solo yo / Privado (regla de TikTok Sandbox). Luego abres tu app de TikTok y le cambias la privacidad a Público en 2 toques.
  2. Modo Bandeja de Entrada (Inbox / Borrador): El video llega como notificación a la bandeja del sistema de tu app de TikTok lista para añadir música en tendencia y publicar como Público.
  3. ☁️ 24/7 con PC Apagado: Nuestro motor en GitHub Actions renueva tu access_token automáticamente usando tu refresh_token y sube tus videos desde Google Drive a la hora programada aunque tu PC esté apagado.
